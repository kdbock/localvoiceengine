# Local Voice Engine at home

This folder can live in iCloud Drive and run on either Mac.

## First time on the MacBook Pro

1. Open this folder from iCloud Drive.
2. Double-click `Start Local Voice Engine.command`.
3. If macOS asks for permission, allow it.
4. Open `http://127.0.0.1:8765/` in a browser.

The first launch may take a few minutes because it builds the local helper environment.

## Daily use

1. Double-click `Start Local Voice Engine.command`.
2. Open `http://127.0.0.1:8765/`.
3. Pick a brand, pick a story, approve text, then create the video.

Finished videos are in `output/videos/`.

## Important

Let iCloud finish syncing before leaving the office or opening the folder at home. Large video files can take a little while.
