# Brand kit template

Use one brand kit per site.

## Required fields

- Site name
- Website domain
- Pronunciation for AI voice
- Tagline
- Logo for light backgrounds
- Logo for dark backgrounds
- Primary color
- Text color
- Background color
- Muted color
- Alert or breaking-news color

## Video use

The brand kit controls the top bar, accent color, caption panel, end card and spoken website line.
